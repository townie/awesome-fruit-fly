### 1. FLM — Fly Language Model — `nftechie` / [@nftechie_](https://x.com/nftechie_)

- **What:** Chat with a frozen 1.2B language model whose next-token scores are nudged by a 278,528-parameter readout of the **full retained MaleCNS graph** (166,700 nodes, 25,582,938 directed edges). Language ability is the pretrained Liquid AI LFM2.5 backbone; the fly graph is a reservoir.
- **Tweet URL:** not independently archived here (no invented ID).
- **Repo / live:** https://github.com/nftechie/flm · https://fly-language-model.vercel.app/ · paper: https://artificialscientific.com/papers/flies-are-all-you-need
- **Dopamine/RL?** no (supervised adapter only; no PAM/PPL pulses).
- **Why it's cool:** nftechie’s post-Doom/Stonkfly move is *talk to the fly*, with a public chat UI. The paper’s own control is the punchline: a parameter-matched **no-graph** readout does slightly better. Causal influence ≠ fly anatomy helping language.
- **Evidence:** fetched README + live HTTP 200; paper fetched; MarkTechPost / Lumien write-ups (12 Sep 2026) quote the same NLL/control numbers. GitHub API: created 11 Sep 2026.

### 2. Same Smell — `anzal1`

- **What:** One cVA puff into **MaleCNS (he)** and **FlyWire (she)** at the same time. He lunges, she pauses — the Cell dimorphism headline as a phone-friendly lab. Extra modes: Pong between the two brains, and a Tinder-style swipe where both courtship circuits judge fake profiles.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/anzal1/samesmell · https://anzal1.github.io/samesmell/
- **Dopamine/RL?** no.
- **Why it's cool:** Best new *scientific-meme* I/O. Uses both sexes’ connectomes, which almost every game demo ignores. README is explicit that LIF timing is stretched and bodies are puppets.
- **Evidence:** fetched README; GitHub Pages HTTP 200 (14 Sep 2026). Repo created 11 Sep 2026.

### 3. swat-or-buy — `oskarmalmwiklund` / Multiply Labs

- **What:** Browser game-show: two (or a bracket of) ads go into a MaleCNS **retina + lamina** (29,195 neurons in-browser). You pick a winner first; the fly “BUYs” the layout-driven glance winner and swats the rest. Python path is the full-brain, null-controlled report.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/oskarmalmwiklund/swat-or-buy · https://swat-or-buy.vercel.app/
- **Dopamine/RL?** no. Named `buy`/`swat` readouts exist; the README greys them out because medulla / T4–T5 / looming cells are **silent** under LIF (graded optic lobe cannot be disinhibited into spikes). Honest `glance`/`boredom` only.
- **Why it's cool:** Ads as photoreceptor stimulus is a new interface. The failed looming/T4–T5 gate is more useful than a fake “the fly liked this creative” claim.
- **Evidence:** fetched README (gate table); live HTTP 200. Created 13 Sep 2026.

### 4. Fly Tic-Tac-Toe — `pikabell`

- **What:** 98 measured MaleCNS cells + a 425-parameter readout play tic-tac-toe in the browser, with **Silence circuit** and in-browser CEM vs minimax-imitation training.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/pikabell/fly-tictactoe · https://pikabell.github.io/fly-tictactoe/
- **Dopamine/RL?** yes (CEM / imitation of the readout only; wiring frozen).
- **Why it's cool:** Same gold-standard controls as Fly Dino, plus the result most viral clips omit: a **degree-preserving rewired** graph scores 0.850 vs the real circuit’s 0.854. Topology is not the skill. Silencing the circuit *does* collapse play.
- **Evidence:** fetched README control table; GitHub Pages HTTP 200. Created 14 Sep 2026. Built on cobanov/fly-connectome-template.

### 7. flybrain-intransitive — `charbelkassab`

- **What:** Full MaleCNS LIF plays *Intransitive* (rock-paper-scissors chess) with **zero training**. Captures/progress look like small objects (LC10a/LC18); danger/open base look like looming (LPLC2/LC4). Score = approach DNs − giant-fiber escape. README: untrained fly 100–0 vs random, 55–45 vs greedy; scrambled wiring 0 vs greedy.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/charbelkassab/flybrain-intransitive (local demo video; no hosted play URL).
- **Dopamine/RL?** no. A learned descending readout **hurt** vs the biological approach/escape pair (38 vs 55 wins).
- **Why it's cool:** Same author as flybrain-snake (already listed). New game + shuffled-wiring control + “training made it worse.” Feature→neuron map is still hand-designed — treat 100–0 vs random as an interface result, not insect chess IQ.
- **Evidence:** fetched README scoreboard. Created 13 Sep 2026. Companion snake repo already in README.
