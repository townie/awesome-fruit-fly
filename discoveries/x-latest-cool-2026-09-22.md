## Hottest new

Ranked by coolness + novelty. “Handle” is the GitHub owner or the X handle when that is the primary source.

### 1. FlySoul — `heyobi`

- **What:** MaleCNS v1.0 LIF fights Iudex Gundyr in SoulsGym. Sensory encoder (bearing, looming, EPG compass, nociception) → biological engine with 1.8 ms delay → eight DN action pools. Damage pulses PPL101 (LTD); a boss hit pulses PAM (LTP). Headline: the biological loop wins **once in ~600** fights and does not learn to; a synthetic readout on the same sensory stream wins about one fight in three. Mock Gymnasium mode needs no DS3 install.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/heyobi/flysoul · https://heyobi.github.io/flysoul/
- **Dopamine/RL?** yes (named PAM / PPL101 three-factor rule; the README is explicit that the fly does not learn the boss).
- **Why it's cool:** New *game* (Souls) with the rare published ceiling (synthetic readout) instead of a vibes clip.
- **Evidence:** fetched README results paragraph; Pages HTTP **200** (22 Sep 2026). Created 19 Sep 2026.

### 2. Model Kombat — `lavallee`

- **What:** A 12,000-neuron MaleCNS sensory→descending→motor subgraph (LPLC2/LC4 looming, LC10a size, male-specific P1, bristles → DNp09 walk, MDN back, TTMn jump, leg/wing MNs punch/guard) fights TypeSafe’s Jev language model in mk.js at 10 decisions/s. Nothing in the fly is trained in advance; a dopamine-like rule updates during the fight. Controls say what each side contributes.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/lavallee/mk-jev-fly-brain · https://lavallee.github.io/mk-jev-fly-brain/
- **Dopamine/RL?** yes (in-fight rule; subgraph, not 166k).
- **Why it's cool:** Best new *versus-LM* I/O. Live in one tab.
- **Evidence:** fetched README; Pages HTTP **200**. Created 18 Sep 2026. 2★ this pass.

### 3. Pokefly — `Reldnahc`

- **What:** Pixel-driven Pokémon Red (PyBoy) on MaleCNS via fly.ai. Fixed spatial adapter, internal synaptic plasticity, fixed seven-button decoder, live dashboard at `127.0.0.1:8777`. Protocol: the same fly keeps learned synapses across whole-game attempts; reaching the battle is part of the task (`-FreshBrain` to reset).
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/Reldnahc/pokefly (local). Distinct from `blackicon-eth/fly-plays-games` (frozen weights, “not a player”).
- **Dopamine/RL?** yes (internal plasticity; not named PAM11/PPL101 in the fetched hero).
- **Why it's cool:** First inspectable *Pokémon Red* loop with an explicit whole-game learning protocol.
- **Evidence:** fetched README. Created 18 Sep 2026.

### 4. pianist-fly — `Noir-infini`

- **What:** Vectorized LIF over the full 166,700 / 25.58M graph. Bilateral sugar-plume concentrations drive 23 antennal sugar receptors; T1L/T1R rates drive Damped Least Squares IK onto 15 piano keys. In-repo mp4s of the 141k-neuron 3D window and key strikes.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/Noir-infini/pianist-fly (local MuJoCo; no public host).
- **Dopamine/RL?** no (frozen graph; sugar is the lure).
- **Why it's cool:** Unique *instrument* I/O on the whole CNS, not a MANC song synth (that is already-ranked `bennjordan/fruitflysynth`).
- **Evidence:** fetched README + GitHub API 3★. Created 20 Sep 2026.

### 5. The Fly’s Table — `WilliamJones`

- **What:** Heads-up blackjack against a measured MaleCNS mushroom body (682 PN, 1,200 KC, 97 MBON, 332 PAM/PPL1). Dopamine-gated KC→MBON depression at the table; a shared brain persists between players. Published: 30,000 solo hands −45% → −16% winrate, 52% basic-strategy agreement; disconnecting dopamine removes the gain. Same repo holds an 80-cell Dino and a Flybody walker, each with a silenced control.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/WilliamJones/fly-blackjack · https://fly-blackjack.vercel.app/
- **Dopamine/RL?** yes (measured DAN types; circuit subset).
- **Why it's cool:** The inspectable blackjack the 17 Sep Inquirer named **without a URL**. Cobanov folded it 19 Sep; this list had not.
- **Evidence:** cobanov README + live HTTP **200**. Created 14 Sep 2026 (missed by 15–17 Sep shards).

### 6. Fly-NAF — `ArtyMend07`

- **What:** All 138,639 FlyWire v783 LIF neurons play FNAF 1. Hallway difference → DNp01 slams doors; DNp09 subthreshold potential raises the tablet; raising it drives GABAergic inhibitors so the fly is **blind on cameras**. Starvation timer forces a 30 s unwatched-hallway look and counts those looks separately. Best run: 4 AM night 2.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/ArtyMend07/Fly-NAF · recording https://www.youtube.com/watch?v=4UNPlA-YJtw (not re-played here). Windows only; no browser host.
- **Dopamine/RL?** no (frozen graph; no trained readout).
- **Why it's cool:** New horror I/O with identified DNs and an honest “what this is not.”
- **Evidence:** fetched README; cobanov #11 on 20 Sep. Created 1 Sep 2026 (late catch).

### 8. fly-swing — `JHC56`

- **What:** 1 mg MuJoCo fly web-swings a random obstacle course. Escape is LC4/LPLC2 → DNp01 Giant Fiber (8 ms later a web fires). Whole 165,122 / 25.6M graph runs as live display. A whitetree kNN threat memory picks web direction. Published 20/20 random courses.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/JHC56/fly-swing (local).
- **Dopamine/RL?** no (memory is kNN on outcomes, not PAM11).
- **Why it's cool:** Honest “there is no dodge code.” Circuit subset drives the body; full graph is the HUD.
- **Evidence:** fetched README; cobanov #9 on 19 Sep. Created 15 Sep 2026 (late catch).

### 9. Haltere Pilot — `Ameerkhanjk`

- **What:** Simulated quadrotor whose IMU enters **haltere afferents** and whose motors are real wing MNs. Tuned gains reach 93% of a teacher. Silencing 204 haltere cells → crash every second; 204 random cells ≈ nothing.
- **Tweet URL:** none verified.
- **Repo / live:** https://github.com/Ameerkhanjk/haltere-pilot (local).
- **Dopamine/RL?** trained gains on frozen topology (not a PAM pulse).
- **Why it's cool:** Best *identified-afferent* drone of this window; the lesion table is the deliverable. Distinct from already-listed FlyDrones (MiniFly webcam) and fly-fpv (PPO hoop course).
- **Evidence:** fetched README. Created 21 Sep 2026.
